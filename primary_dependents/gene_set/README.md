# Gene Set Usage Notes

This directory contains GMT gene set files used for enrichment analyses in this repository.

## Source

These files are derived from publicly available MSigDB collections (for example, Hallmark, KEGG, Reactome, GO, and ImmuneSigDB).

## Usage Terms

Use of MSigDB-derived content is subject to the current MSigDB terms and licensing from the Broad Institute.

Before reusing or redistributing these files (or derivative outputs), verify that your intended use complies with the current terms:

- MSigDB site: https://www.gsea-msigdb.org/gsea/msigdb
- Terms and license pages linked from the MSigDB site

## Repository Scope

These files are included only to support reproducibility of the analyses in this repository.
